# SDI - Digital Agency Website

Official website for SDI, a digital agency based in Madagascar. 
Built from scratch with PHP, JavaScript, HTML, and CSS.

🔗 Live site: [sdimada.com](https://sdimada.com)

## Features

- Company presentation and services overview
- Portfolio showcase
- Photo gallery
- Team page
- Contact system
- Working login system
- Location-based functionality
- User registration (pending activation)

## Tech Stack

- *Back-end:* PHP
- *Front-end:* JavaScript, HTML5, CSS3
- *Design:* Custom, responsive layout

## About

This project was designed and developed by me as founder of SDI, 
covering the full process from UI/UX design to back-end logic and 
deployment.
